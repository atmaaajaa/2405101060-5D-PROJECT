Repository ini berisi source code, dokumentasi hasil pengerjaan Ujian Tengah Semester (UTS)
mata kuliah Pemrograman Web Dasar.

## Deskripsi Pengerjaan UTS

Website company profile **Atma Creative**, agensi yang bergerak di bidang
UI/UX Design dan IT Consulting. Website menampilkan profil perusahaan beserta
layanan dan portofolionya dengan tampilan modern bernuansa terracotta, dibangun
menggunakan HTML, CSS, dan JavaScript.

## Fitur yang Diimplementasikan

1. Navbar dengan logo Atma Creative, menu (Beranda, Tentang Kami, Layanan, Portofolio, Tim, Kontak), indikator menu aktif, dan tombol "Konsultasi Sekarang"
2. Hero section berisi badge "Agensi Desain & Konsultan IT Terpercaya", headline "Mentransformasi Visi Bisnis Menjadi Pengalaman Digital Intuitif", dan deskripsi singkat perusahaan
3. Tombol call-to-action "Konsultasi Sekarang" dan "Lihat Portofolio Kami"
4. Ilustrasi mockup dashboard di sisi kanan hero (jendela browser, grafik konversi, dan panel kode cloud architecture)
5. Statistik perusahaan: 45+ proyek berhasil dirilis, 99.4% kepuasan mitra klien, 100% eksekusi tepat waktu
6. Daftar klien/mitra: Bank Nusantara, Agritech Asia, Medika Health, Logistik Go, Edukasi Pintar
7. Section Tentang Kami, Layanan, Portofolio, Tim, dan Kontak yang terhubung ke menu navbar
8. Smooth scroll saat menu navbar diklik
9. Tampilan responsif untuk desktop, tablet, dan mobile

## Struktur Folder

- `uts/`: Source code dan file pendukung UTS.
- `uts/css/style.css`: Styling website.
- `uts/js/script.js`: Interaksi website.
- `uts/screenshots/`: Bukti visual hasil implementasi.

## Cara Menjalankan Aplikasi

1. Clone repository ini
2. Buka folder `uts/`
3. Buka file `index.html` di browser
